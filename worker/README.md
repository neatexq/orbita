# orbita-check — проверка ответов «Орбиты»

Маленький сервер (Cloudflare Worker), который спрашивает у нейросети, существует ли то, что ввёл игрок, и подходит ли оно к вопросу. Каждый уникальный ответ проверяется один раз: вердикт сохраняется в хранилище Cloudflare KV и дальше берётся оттуда.

Всё бесплатно, банковская карта не нужна. Понадобятся Windows, интернет и установленный [Node.js](https://nodejs.org) (версия LTS, ставится обычным установщиком «Далее → Далее»).

## 1. Ключ нейросети (Groq)

1. Откройте https://console.groq.com и зарегистрируйтесь (можно через Google).
2. Слева выберите **API Keys** → **Create API Key**, назовите, например, `orbita`.
3. Скопируйте ключ (начинается с `gsk_`) и пока сохраните в Блокнот. Его показывают **один раз**. Никому его не отправляйте и никуда не вставляйте, кроме команды из шага 4.

## 2. Аккаунт Cloudflare

Зарегистрируйтесь на https://dash.cloudflare.com/sign-up и подтвердите почту. Домен покупать не нужно.

## 3. Вход из командной строки

1. Скачайте игру: https://github.com/neatexq/orbita → зелёная кнопка **Code** → **Download ZIP**, распакуйте (или `git clone https://github.com/neatexq/orbita`). Откройте распакованную папку в Проводнике, затем папку `worker`.
2. Кликните в адресную строку Проводника, введите `cmd` и нажмите Enter: откроется чёрное окно, уже в нужной папке.
3. Выполните:

   ```
   npx wrangler login
   ```

   На вопрос «Ok to proceed?» ответьте `y`. Откроется браузер, нажмите **Allow**.

## 4. Хранилище и секреты

1. Создайте хранилище вердиктов:

   ```
   npx wrangler kv namespace create VERDICTS
   ```

   В ответе будет строка вида `id = "3f2a…"`. Откройте `worker\wrangler.toml` в Блокноте и замените `PASTE_YOUR_KV_NAMESPACE_ID_HERE` на этот id (кавычки оставьте). Сохраните. Если wrangler спросит, добавить ли настройку в файл сам, можно ответить «нет» и вставить id вручную.

2. Сохраните ключ Groq как секрет (он хранится у Cloudflare, а не в файлах игры):

   ```
   npx wrangler secret put LLM_KEY
   ```

   Вставьте ключ (правый клик в окне = вставить; символы не отображаются, это нормально) и нажмите Enter.

3. Придумайте длинный пароль для страницы модерации (`tools/review.html`), например 30+ случайных букв и цифр. Сохраните его в надёжном месте и выполните:

   ```
   npx wrangler secret put ADMIN_TOKEN
   ```

## 5. Публикация

```
npx wrangler deploy
```

В конце появится адрес вида `https://orbita-check.<ваше-имя>.workers.dev`. Откройте его в браузере: должно показаться `{"ok":true,"service":"orbita-check"}`.

**Скопируйте этот адрес и пришлите его Claude**, чтобы он прописал его в настройки игры.

После любых правок `wrangler.toml` снова выполните `npx wrangler deploy`.

## Бесплатные лимиты (честно)

- **Groq**: бесплатный план ограничен по запросам в минуту, в день и по токенам, отдельно для каждой модели. Для `llama-3.3-70b-versatile` сторонние источники называют около 30 запросов в минуту и около 1000 в день, но цифры меняются, а в официальной документации цифр для этой модели мы не нашли. Точные значения для вашего аккаунта смотрите на странице лимитов: https://console.groq.com/settings/limits. Благодаря кэшу лимит тратится только на **новые** ответы: повторные «воробьи» нейросеть не спрашивают.
- **Cloudflare Workers (бесплатно)**: 100 000 запросов в день. В **KV**: 100 000 чтений и 1 000 записей в день. Запись происходит один раз на новый ответ, так что 1000 новых ответов в день — реальный потолок. Актуальные цифры: https://developers.cloudflare.com/workers/platform/pricing/
- Воркер сам ограничивает одного игрока: 20 новых проверок в минуту (кэшированные не считаются).
- Если нейросеть недоступна или лимит исчерпан, воркер отвечает `503`, и игра просто пишет «не засчитано» (часы во время проверки стоят, так что время не теряется).

## Другая нейросеть (по желанию)

Подходит любой сервис с OpenAI-совместимым адресом `chat/completions`. Меняются только `[vars]` в `wrangler.toml` и секрет `LLM_KEY`, затем `npx wrangler deploy`.

### Google Gemini

1. Ключ: https://aistudio.google.com/apikey → **Create API key**.
2. В `wrangler.toml`:

   ```
   LLM_URL = "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions"
   LLM_MODEL = "gemini-3.8-flash"
   LLM_MAX_TOKENS = "1024"
   LLM_EXTRA = '{"reasoning_effort":"low"}'
   ```

   Имя модели — пример: актуальные названия Flash-моделей смотрите в AI Studio. Модели Gemini «думают» перед ответом, поэтому лимит токенов нужен больше.
3. `npx wrangler secret put LLM_KEY` и вставьте ключ Gemini.

Бесплатные лимиты Gemini зависят от модели и меняются: проверьте их на странице лимитов в AI Studio.

### Cloudflare Workers AI (без отдельного сервиса)

1. Узнайте **Account ID**: dash.cloudflare.com → справа на главной странице аккаунта (или в разделе Workers & Pages).
2. Создайте токен: **My Profile → API Tokens → Create Token**, шаблон **Workers AI**.
3. В `wrangler.toml` (подставьте свой Account ID):

   ```
   LLM_URL = "https://api.cloudflare.com/client/v4/accounts/ВАШ_ACCOUNT_ID/ai/v1/chat/completions"
   LLM_MODEL = "@cf/meta/llama-3.3-70b-instruct-fp8-fast"
   ```
4. `npx wrangler secret put LLM_KEY` и вставьте этот токен.

Бесплатно доступно 10 000 «нейронов» в день. Сколько это проверок, зависит от модели; смотрите https://developers.cloudflare.com/workers-ai/platform/pricing/

## Проверка без аккаунтов

```
node worker/test/run.mjs
```

Тест поднимает фейковую нейросеть и хранилище в памяти и проверяет кэш, лимиты, защиту от «взлома» ответа и админку.
